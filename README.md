# Indentation-Yield-Analyzer

本项目是一套用于分析金属材料（特别是块体非晶合金）纳米压入试验数据的自动化工具集。基于 Python 开发，旨在通过载荷-位移（P-h）数据和压痕形貌参数提取材料的本构关系参数，如表征应力（$\sigma_r$）和屈服强度（$\sigma_y$）。

## 核心功能模块

### 1. 载荷-位移数据处理 (calculate_C.py)
* **自动化分组**：支持多列并排或垂直堆叠格式的原始数据读取。
* **数据清洗**：内置基于中位数绝对偏差的异常点剔除机制。
* **物理拟合**：执行 $m=2$ 约束下的 Kick 定律拟合，提取加载曲率系数 $C$。
* **稳态识别**：采用中段锚定与双向截断算法，自动排除压痕尺寸效应（ISE）及大载荷下的剪切带干扰，提取本构响应。

### 2. 经典本构参数求解引擎
项目集成了三种基于物理力学推导的主流参数提取模型：
* **Yao 模型 (yao_sigma_r.py)**：基于 CR-EMI 能量法，利用 $C$ 值与等效弹性模量 $E^*$ 求解隐式方程获得 $\sigma_r$。
* **Dao 模型 (dao_sigma_r.py)**：基于量纲分析，利用压痕形貌比 $h_p/h_{max}$ 求解隐式多项式方程提取特征参数。
* **Xu 模型 (xu_sigma_r.py)**：利用弹性回复比 $h_e/h_{max}$ 进行显式解析求解屈服强度。

### 3. 基于遗传编程的符号回归探索引擎 (advanced_symbolic_regression.py)
引入机器学习方法以探索未知的物理本构关系：
* **自动方程推导**：基于 PySR 算法，利用交叉与变异操作在特征空间（如 $E_r$, $h_p/h_{max}$ 等）中寻找目标参数（$\sigma_y$）的最优代数表达式。
* **维度自适应可视化**：程序根据发现的最佳公式的实际变量维度，自动生成二维物理曲线图或三维物理曲面图。
* **语法树解析**：利用原生 Matplotlib 引擎递归渲染最佳公式的抽象语法树（AST），提供底层逻辑的可视化拆解。

### 4. 多模量并行验证机制
* 支持同时导入多种来源的弹性模量数据进行并行计算。
* 自动生成包含真实值与预测值的对角线（$y=x$）交叉验证散点图，以直观评估模型计算的偏离度。

## 目录结构
* `/data/Pd_Fn`: 存放原始压入试验数据的文本文档。
* `/data/knowndata.csv`: 存放材料的已知属性，包括弹性模量、形貌比以及验证所需的参考屈服强度。
* `/output/yao_C`: 存放加载曲率系数 $C$ 的计算过程图及汇总数据表。
* `/output/yao_sigma_r`: 存放 Yao 模型提取表征应力的计算结果。
* `/output/dao_sigma_r`: 存放 Dao 模型提取参数的计算结果。
* `/output/xu_sigma_r`: 存放 Xu 模型解析求解的计算结果。
* `/output/sym_reg`: 存放符号回归引擎的探索结果，以特征组合与时间戳命名的独立子文件夹保存，包含候选方程列表、拟合精度图、物理函数曲线/曲面图以及抽象语法树图。

## 环境与依赖要求
* 语言：Python 3.8 或更高版本
* 核心计算与处理库：`numpy`, `pandas`, `scipy`, `sympy`
* 可视化库：`matplotlib`
* 机器学习后端：`pysr` (注：PySR 底层依赖 Julia 语言环境，首次运行将自动触发环境配置)
