# Indentation-Yield-Analyzer

本项目是一套用于分析金属材料（特别是块体非晶合金）纳米压入试验数据的自动化工具集。基于 Python 开发，旨在通过载荷-位移（P-h）数据和压痕形貌参数提取材料的本构关系参数，如表征应力（$\sigma_r$）和屈服强度（$\sigma_y$）。

## 核心功能模块

### 1. 载荷-位移数据处理 (calculate_C.py)
* **自动化分组**：支持多列并排或垂直堆叠格式的原始数据读取。
* **数据清洗**：内置基于中位数绝对偏差的异常点剔除机制。
* **物理拟合**：执行 $m=2$ 约束下的 Kick 定律拟合，提取加载曲率系数 $C$。
* **稳态识别**：采用“中段锚定与双向截断”算法，自动排除压痕尺寸效应（ISE）及大载荷下的剪切带干扰，提取本构响应。

### 2. 本构参数求解引擎
本项目集成了三种主流的力学推导模型：
* **Yao 模型 (yao_sigma_r.py)**：基于 CR-EMI 能量法，利用 $C$ 值与等效弹性模量 $E^*$ 求解隐式方程获得 $\sigma_r$。
* [cite_start]**Dao 模型 (dao_sigma_r.py)**：基于量纲分析，利用压痕形貌比 $h_p/h_{max}$ 求解隐式方程 [cite: 12]。
* **Xu 模型 (xu_sigma_r.py)**：利用弹性回复比 $h_e/h_{max}$ 进行显式解析求解。

### 3. 多模量并行验证
* 支持同时导入 4 种来源的弹性模量数据进行并行计算。
* 自动生成 $y=x$ 交叉验证散点图，用于评估计算值与参考屈服强度 $\sigma_{y,m}$ 的偏差。

## 目录结构
* `/data/Pd_Fn`: 存放原始压入试验数据（.txt）。
* `/data/knowndata.csv`: 存放材料的已知属性（弹性模量、形貌比等）。
* `/output/yao_C`: 存放 $C$ 值计算过程图及汇总表。
* `/output/yao_sigma_r`: 存放 Yao 模型计算结果。
* `/output/dao_sigma_r`: 存放 Dao 模型计算结果。
* `/output/xu_sigma_r`: 存放 Xu 模型计算结果。
